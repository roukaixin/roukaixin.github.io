Landscape 路由器安装

 不北咪 收录于 软路由 和 Landscape 软路由
2025-10-11 10:40 2026-09-03 14:59 约 200 字 预计阅读 1 分钟 - 次阅读  
目录

前提条件

安装好 debian13 最新系统。

安装 pppoe 软件包。

信息

如果未安装 pppoe 软件包，可以使用 apt install pppoe 命令安装。需要使用 root 权限执行。

安装 landscape

GitHub 地址：landscape

文档地址：landscape 文档

dns

安装成功之后，默认有一个名字为 Landscape Router Default DNS Upstream 的 dns 上游。 并且有一个名字为 Landscape Router default rule，优先级为 10000 的 dns 规则。
