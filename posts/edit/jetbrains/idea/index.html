Failed to retrieve application JMX service URL 报错

错误信息

启动项目时候，消息中心中出现 Failed to retrieve application JMX service URL 错误信息。

解决方案

方法一: 通过在 Run/Debu Configurations -> Modify options 禁用 JMX 端口

方法二： 在临时文件中删除 hsperfdata_用户名，重启

  • window 路径 c:\\Users\用户名\AppData\Local\Temp

  • linux 路径 /tmp

fcitx5 在 idea 显示框位置不正确

高版本 idea 不需要设置，默认已经解决

解决方法：

  • ctrl + shel + a 打开搜索 actions，搜索 choose boot java runtime for the ide

  • 搜索后按下回车键打开它

        选择第一个即可，b后面的数字越大版本越新

  • 现在之后安装重新 idea 即可
